# games/ — per-game research

One directory per game. Each is a **vertical pass** (see `../PLAN.md`), producing:

```
games/<game>/
  SOURCES.md    source list + quality triage for this game (indexed in ../../SOURCES.md)
  MECHANICS.md  cited systems map (currencies, generators, upgrades, prestige, offline, caps)
  MATH.md       formulas + Markdown tables GENERATED from data/*.csv
  data/*.csv    the math artifact (machine-readable, one table per concept)
  ANALYSIS.md   pacing analysis + design lessons for our clicker tower-defence
  VERIFY.md     independent verification findings + PASS/FAIL verdict
```

Order: **cookie-clicker → exponential-idle → revolution-idle → leaf-blower-revolution.**

Rules: every number cites a source; CSVs are generated by `../../tools/<game>/`
and regenerate the Markdown tables; raw artifacts live in the gitignored
`../reference/`.
